# MXSIG2026SIVV

MXSIG2026SIVV es un Sistema de Información Geográfica (SIG) que permite visualizar y consultar información territorial mediante mapas interactivos.

## ¿Qué es un SIG?

Un SIG organiza información que tiene una ubicación geográfica. En un mapa, la información se agrupa en capas. Cada capa representa un tema distinto, como límites territoriales, localidades o indicadores estadísticos. Al ver varias capas juntas, puedes entender dónde se distribuye un fenómeno y cómo se relaciona con otros elementos del territorio.

## ¿Qué puedes hacer con MXSIG2026SIVV?

- **Explorar el mapa.** Acércate, aléjate y desplázate para revisar una zona a la escala que necesites.
- **Combinar capas temáticas.** Activa las capas de interés y consulta su leyenda para interpretar colores y símbolos.
- **Consultar información de un elemento.** Selecciona un punto o un área representada en el mapa para ver los datos disponibles sobre ese elemento.
- **Medir distancias y superficies.** Traza una línea o delimita un área para estimar su longitud o superficie.
- **Comparar información territorial.** Superpón capas para observar cómo coinciden los límites, las localidades y otros datos disponibles en una misma zona.

## Ejemplo de uso

Para estudiar cómo se distribuye un indicador territorial, puedes activar su capa junto con la de límites municipales, consultar la leyenda y seleccionar un área para revisar su información. Así puedes ubicar el indicador en el mapa y comparar su distribución entre zonas.
