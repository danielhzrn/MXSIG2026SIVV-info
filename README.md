# MXSIG2026SIVV

MXSIG2026SIVV es un Sistema de Información Geográfica (SIG) que permite visualizar y consultar información territorial mediante mapas interactivos.

El sistema facilita la exploración de capas geográficas y la consulta de información asociada a los elementos del mapa. Su objetivo es apoyar el análisis territorial y facilitar el acceso a información geográfica.
